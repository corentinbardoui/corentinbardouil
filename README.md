# corentinbardouil.com

Bilingual showcase site (French and English), live at [corentinbardouil.com](https://www.corentinbardouil.com).

## Stack

Next.js (App Router), TypeScript, plain CSS, Cal.com for booking, Formspree for requests, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

```bash
npm run build      # Production build
npm run lint       # ESLint
npx tsc --noEmit   # Type-check
```

Architecture and editing notes are in [CLAUDE.md](CLAUDE.md).
